# Mori Cuts

Самостоятельный сайт с регистрацией, кабинетом клиента, записью, админкой и SQLite. Это независимое предложение реальному бизнесу. Демо-заявки не отправляются компании.

## Запуск

Нужен Node.js 24+. Установка зависимостей не требуется.

1. Запустите START.cmd или выполните `node server.mjs` в этой папке.
2. Откройте http://127.0.0.1:8771 .
3. Для владельца запустите OWNER.cmd или `node owner.mjs` и задайте собственный пароль. Затем войдите на /account.html и откройте /admin.html.
4. Для клиента создайте отдельный тестовый аккаунт через страницу Sign in → Create account.

Общего админского пароля нет. Тестовые аккаунты и базы в архив не включены. В Windows запуск использует Node из PATH или, если доступен, встроенный Node Codex.

## Возможности

Каталог услуг и цен; профили мастеров; выбор времени с проверкой пересечений; статусы и отмена записей; управление услугами/мастерами/датированными рабочими интервалами; загрузка JPEG/PNG/WebP; список клиентов; фильтры; CSV; журнал действий. Изменение прайса не меняет цену старой записи.

## Эксплуатация

- `node test.mjs` — интеграционные проверки с отдельной временной базой.
- `node backup.mjs` — резервная копия базы и фотографий.
- `node recover.mjs` — приватное восстановление пароля существующего пользователя без изменения роли.
- Данные хранятся в `data/`, которая создаётся при первом запуске. Не загружайте её в публичный репозиторий.
